# Smart Servers
A set of self hosted services configurations

Services are running in Docker containers

## Self Hosted Services
* JellyFin - Media Library. Share and play media from HDD [Smart JellyFin](http://localhost:8096)
* FileBrowser - File share. Share HDD files to view/edit from other systems [Smart FileBrowser](http://localhost:8080)
* ExcaliDraw - Design platform [Smart ExcaliDraw](http://localhost:)
* Immich - Photo and video management solution [Smart Immich](http://localhost:2283)
* Actual - Finance Manager [Smart Finances](http://localhost:5006)
* Obsidian - Note taking app. [Smart Obsidian](http://localhost:*)
* TimeTagger - Time management app [Smart TimeTagger](http://localhost:80)
* AdventureLog - Trip logging app with Immich integration [Smart AdventureLog](http://localhost:8000)
* StirlingPDF - PDF Editor & Converter [Smart StirlingPDF](http://localhost:8080)

## Archived Self Hosted Service
* Photostructure - A self hosted photo organizing app with duplicate detection [Smart PhotoStructure](http://localhost:1787)
* PhotoPrism - A self hosted photo organiser, with AI support [Smart PhotoPrism](http://localhost:2342)
* FireFly III - A Financial Manager. Debugging required, as importer not working [Smart Finance](http://localhost:*)
* Memos - Twitter like feed. Multi user support [Smart Memos](http://localhost:*)
